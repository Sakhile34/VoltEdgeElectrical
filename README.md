## Project Overview
VoltEdge Electrical is a website built for a fictional electrical services
company based in Mbombela. The site provides information about the
company's services, allows visitors to make enquiries, and provides
contact details and locations. The website was built using HTML, CSS,
and (in Part 3) JavaScript.

## Website Goals and Objectives
- Provide a professional online presence for VoltEdge Electrical
- Clearly showcase the company's services
- Allow potential customers to easily make enquiries
- Provide contact information and location details for multiple branches
- Ensure the website is responsive and accessible on all devices

## Key Features and Functionality
- 5 fully linked pages: Home, About, Services, Enquiry, Contact
- Responsive navigation menu across all pages
- Enquiry form with service selection dropdown
- Contact form and two branch locations with embedded maps
- Responsive design tested across desktop, tablet, and mobile screen sizes

## Sitemap
